# homebrew-seam

```
brew install booka66/seam/seam
```

The formula for [seam](https://github.com/booka66/seam). A new release is a tag
there, then `url` and `sha256` in `Formula/seam.rb` bumped to match:

```
curl -sL https://github.com/booka66/seam/archive/refs/tags/vX.Y.Z.tar.gz | shasum -a 256
```
